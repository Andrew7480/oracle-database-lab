# Oracle Database Lab — (Training Edition — Academic Version)

Training repository for Oracle Database administration, testing, change management and Git workflows.

Name: Andres Cardozo Martinez
Professor: Richard Aviles Lopez

En este laboratorio se trabajaron los conceptos fundamentales de Git y su uso dentro de un flujo de desarrollo de software. A través de diferentes ejercicios se practicó la creación y configuración de un repositorio, el manejo de la Staging Area, la realización de commits, la creación y gestión de branches y la conexión de un repositorio local con GitHub.
